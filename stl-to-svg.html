STL to SVG

A solid becomes a closed cutting drawing, in millimetres, for Makera Studio. Double-click this file, next to the editor and the gear page. Nothing is installed, and nothing is sent off this computer.

View and slice

The coloured rectangle is the slice. Only the walls it crosses become the cut.

Gaps smaller than this can be joined. On an intricate ornament, 0.05 mm keeps a real slot from closing. You are asked before any gap is joined.

Attach joins each loose piece to the nearest surrounding material. A box or circle you draw is kept, so a loose piece it covers stays joined where you paint. You are asked before the cut changes.

Opening the file, and cutting a 1.25 mm ornament
  1. Double-click stl-to-svg.html in the same folder as the NC editor. The page opens from the disk. There is no server and no library to install.
  2. Press Load STL, or press Sample ornament. The sample is a 50 mm disk, 1.25 mm thick, with a through hole, a loose inner disk, and a recess that does not go through.
  3. Press Top for a sheet lying flat. Front and Side look at the edge. Drag the solid, then press Use this view if the slice should follow that look.
  4. Leave the slice in the middle of a 1.25 mm sheet. A through hole stays. A shallow recess disappears. Slide the plane near the top and generate again to see the recess become an opening.
  5. Press Profile from this view for the outline of the whole solid in that direction. A hole stays where you can see straight through. A recess that stops partway is filled in. The slice height is not used.
  6. Press Generate cutting pattern. Pale is the acrylic that stays. The ground colour is what the cutter removes. The loose colour is a piece that will come loose.
  7. If gaps are listed, read the warning. Repair only if those gaps are breaks in the outline, not slots you want to keep.
  8. A loose piece can be joined to the rest. Attach loose pieces uses a strip of the bridge width at the nearest gap. Draw box or Draw circle to paint the place yourself, from the loose piece onto the material that stays. The page asks before the cut changes. Generate again starts over from the slice.
  9. Press Export SVG. Every path in the file is closed. The width and height are millimetres, and 1 unit in the file is 1 mm. In Makera Studio, check that the imported width matches the size shown here before you cut.

Hover a dotted name for a short explanation. Paper, Dark, Warm summer, and Cool autumn are the same drawing in other colours. The path is the centre of the cut. The file does not offset for a bit. This page writes an SVG. It does not write an NC file, and it does not run the machine.
